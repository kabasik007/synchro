# Synchro roadmap

v0.1: Rust egui drag-and-drop desktop sender; Kotlin Android 10+ HTTP receiver, token pairing, MediaStore Downloads, checksum and system APK installer.
v0.2: On-device validation, automatic mDNS/QR pairing, better progress notifications, Android receiver error diagnostics, opt-in folder watching.
v0.3: USB/Wi-Fi ADB install-r workflow for developer devices, latest APK build auto-selection, resumable uploads, devices/history.
v0.4: Optional self-hosted aaPanel relay with end-to-end encryption and expiration. Never expose the Android receiver directly to the Internet.
