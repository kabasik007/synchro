# Synchro — затверджений дизайн-референс

![Цільовий дизайн Synchro: Windows + Android](./synchro-target-2026-10.png)

## Статус

**Основний затверджений візуальний орієнтир (Source of Truth)** для подальшої розробки Synchro Desktop (Rust + egui) та Synchro Android (Kotlin). Референс запропоновано й затверджено користувачем 19 жовтня 2026 року.

- Оригінальний PNG: [synchro-target-2026-10.png](./synchro-target-2026-10.png)
- Роздільність: **1672 × 941**
- SHA-256 оригіналу: `8d9b107b8a18bef4d0d6c7ce3b616c5ba8f2a0416d5bd98d6427cc9fa549b127`
- Важливо: зображення — *концептуальний макет*, а не скріншот готової функціональності. Усе, що показано в UI, повинно відповідати реальним можливостям застосунку.

## Візуальні принципи

### Windows: темний сучасний інтерфейс

- Темно-синій майже чорний фон із делікатними градієнтами.
- Електрично-синій акцент для активної навігації, кнопки «Відправити» та індикаторів передачі.
- Відокремлена вузька бічна панель з логотипом Synchro і пунктами **Transfer / Device / Settings / About** (українська локалізація теж потрібна).
- Великий заголовок **Fast file transfer from PC to Android**, мініілюстрація ПК → Wi-Fi → Android.
- Картки з акуратними заокругленнями, тонким контуром, рівними відступами, єдиною типографікою та стриманими іконками.
- Двоколонкова головна зона на широких екранах; при меншій ширині картки складаються вертикально, доступний скрол.
- Видимі порожні, завантажувальні, успішні та помилкові стани; контрастний текст і доступна клавіатурна навігація.

### Android: світла чиста тема

- Світлий фон із синіми акцентами, великими заголовками та округлими картками.
- Зверху: **Synchro · Android**, опис і налаштування.
- Статус реального приймача: **Ready to receive** лише коли сервіс слухає порт.
- Окремі адреси Wi-Fi / Tailscale, токен сполучення та кнопки копіювання.
- Підтверджене сполучення з ПК і керування прийманням.
- Список завантажень з іконкою типу файлу, назвою, розміром, датою та **Install** для APK.
- Реальний Android Package Installer із системним підтвердженням; жодних обіцянок «тихого встановлення».

## Склад екранів та поведінка

| Елемент | Desktop | Android | Вимога |
| --- | --- | --- | --- |
| Статус | Картка пристрою + індикатор | Ready / Stopped | Перевіряти фактичне з’єднання, не малювати фіктивний статус |

## Поточна реалізація Desktop

У v0.5 додано окрему дизайн-систему Rust/egui (`desktop/src/design.rs`) та оновлено
головні компоненти інтерфейсу, не змінюючи цей затверджений PNG.
Карта відповідності референсу, тест-кейси та обмеження — [IMPLEMENTATION-0.5.0.md](./IMPLEMENTATION-0.5.0.md).
Візуальне порівняння на реальних Windows DPI ще потрібно виконати.

## Реалізація поетапно

1. **Desktop UI fidelity.** Привести існуючий Rust/egui v0.2 до композиції макета: навігація, шапка, картки, зона drop, черга, кнопки, темна палітра. Не ламати надсилання файлів.
2. **Android UI fidelity.** Переробити нинішній нативний екран на картковий світлий макет; коректно показувати IP/Tailscale, токен, статус і отримані файли.
3. **Pairing.** Узгодити справжній формат QR і підтвердження з’єднання. Додати QR-сканування або сполучення через код.
4. **Transfer experience.** Індивідуальний прогрес, історія, повторення помилок, зрозумілі стани, нотифікації та інсталятор APK.
5. **Полірування.** Тест DPI 100–200%, різні розміри вікна Windows і дисплеї Android, темна/світла системні теми, доступність, локалізація.

## Критерії приймання

- Відкритий головний екран візуально близький до цільового референсу **за компонуванням, ієрархією, кольорами, розмірами та типографікою**.
- Окремо перевірена відповідність desktop та Android; немає вертикального/горизонтального обрізання вмісту.
- Жоден стан або кнопка не є декоративною підробкою: якщо функція ще не готова, явно маркувати як у розробці.
- Робочі drag-and-drop, реальна передача файлу, SHA-256, показ отриманого APK та відкриття системного інсталятора не регресували.
- Уся реалізація й документація лишаються в одному репозиторії `kabasik007/synchro`.

**Не замінювати цей референс новими стилями без явного рішення.** Нові ітерації порівнювати з ним.
