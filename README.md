# Synchro

Fast PC → Android file transfers, built for sending APK builds without messengers.

This repository is being initialized with a Rust desktop sender and native Android receiver. The first version focuses on authenticated, direct transfers on the same Wi‑Fi (or a private Tailscale network), a visible `Download/Synchro/Debug` folder, and an explicit Android APK installation flow.

See the incoming project files and `docs/PROTOCOL.md` for the implementation and setup instructions.
