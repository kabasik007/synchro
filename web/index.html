⚙ Початкове налаштування адміністратора

На сервері створи SYNCHRO_ADMIN_TOKEN. Введи його тут, щоб одноразово видати окремі токени для Windows та Android. Адмінтокен не зберігається в браузері.

Новий токен показується лише один раз. Збережи його в менеджері паролів. Не передавай адмінтокен пристроям.
