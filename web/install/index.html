STEP 01 / 04

Твій хмарний диск.
На твоєму сервері.

Майстер налаштування Synchro Internet Mode. Зв'яжемо Windows і Android через HTTPS — без відкритих портів на пристроях.

Перевірка сервера

Нам потрібні aaPanel з HTTPS і запущений Rust Synchro Server.

Перевіряємо…
○
HTTPS і доменПеревірка URL
○
Rust API через NginxПеревірка /health
○
Стан інсталяціїSQLite створюється Rust-сервером автоматично
ⓘ

Спершу потрібно встановити системну службу один раз: через SSH або консоль aaPanel. Інсталятор не виконує команди з правами root і не змінює Nginx автоматично.

STEP 02 / 04

Налаштування сервера

Авторизуйся одноразово секретом адміністратора та перевір, що SQLite й файлове сховище працюють.

Зчитується з приватного /etc/synchro/synchro.env. Не зберігається у браузері чи LocalStorage.
Домен змінний. Майстер збереже адресу в SQLite, але DNS і SSL налаштовуються в aaPanel/Cloudflare.
